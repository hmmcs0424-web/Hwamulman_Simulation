화물정보 등록

기본 등록 순서

상차지 → 하차지 → 톤수·차종 → 화물명 → 운임 → 지불방식 → 등록(F3) 버튼 순서로 입력합니다.

등록 완료 후 "화물정보 등록완료" 메시지가 뜨고, 폼이 초기화되며 목록 맨 위에 새 행이 추가됩니다.

주소 검색

상차지·하차지는 도로명이 아닌 시도·시군구·읍면동으로 검색합니다.

  1. 주소 칸에 지역명 입력 후 엔터
  2. "주소 검색" 목록이 나타나면 행을 더블클릭하여 선택
  3. 선택 시 왼쪽 칸 = 시도, 입력칸 = "시군구 읍면동"으로 자동 입력
목록 맨 위 행은 읍면동 없이 시군구 단위 행입니다. 동·리 단위 지정이 필요할 경우 아래 행을 선택하세요.

거리·시간 및 AI 추천 운임

두 주소 선택 시 입력칸 오른쪽에 자동 표시됩니다.

항목표시 예시
거리/시간거리 : 약 406.19 km / 시간 : 약 05시간 10분 (서울→부산 기준)
AI 추천 운임AI 추천 : 390,000 원 → 클릭 시 최저/최고 운임 팝업 표시

금칙어 처리

화물명에 무게·중량 관련 단어가 포함되면 포커스가 벗어날 때 자동 삭제됩니다.

삭제 대상 단어: 무게, 중량, T, t, Ton, ton, kg, k g, 톤, ⓣ (공백·점·쉼표·슬래시 변형 포함)
알림창: "금칙어(톤, T, 중량 등)를 사용하여 자동 삭제 됩니다."

차주운임 제안 허용

체크 시 화물명 앞에 운임제안)이 자동으로 붙고, 해제하면 사라집니다.

운임 계산 규칙

산재보험료

총운임 × 1.1 × 0.4% → 10원 단위 반올림

차주운임산재보험료
300,000원1,320원
320,000원1,410원
값이 있으면 라벨이 "차주산재보험료 부담분"으로, 없으면 "산재보험료 부담분"으로 표시됩니다.

차주지급운임 (부가세포함)

총운임 × 1.1 − 산재보험료

총운임차주지급운임(부가세포함)
