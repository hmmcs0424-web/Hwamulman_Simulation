화물정보
경로: 상단 첫 메뉴 (화물정보)
화물(오더)을 등록하고, 등록한 오더의 배차 상태를 확인·관리하는 메인 화면입니다. 위에서부터 등록 폼 → 검색·필터 → 목록 → 하단 요약 순서입니다.

사용 순서

  1. 상차지·하차지 칸에 "서울 중" 처럼 입력하고 엔터 → "주소 검색" 목록에서 행을 더블클릭 (도로명이 아니라 시도/시군구/읍면동 검색)
  2. 톤수 → 차종 → 화물중량 순으로 선택 (중량은 톤수 기준 110% 이하)
  3. 지불방식 선택. 선불·착불일 때만 수수료 입력 가능
  4. 차주운임·수수료 입력 → 총운임, 산재보험료, 차주지급운임 안내가 자동 계산
  5. 상차일/하차일 선택 (라디오 또는 F9~F12) 후 등록(F3)

알아둘 규칙

  • 총운임 = 차주운임 + 수수료, 최대 300만원
  • 산재보험료 = 총운임×1.1×0.4% (10원 단위 반올림)
  • 화물정보에 무게·중량·t·ton·kg·톤 등은 금칙어 → 칸을 벗어나면 알림 후 삭제
  • 하차일시는 상차일시보다 빠를 수 없음
  • F1 화물등록(팝업), F2 초기화, F3 등록/수정, F4 접수시간변경(1분 이내 재변경 불가), F5 검색, F6 오더 추가, F7 복사
💡 목록 행을 우클릭하면 상태별 메뉴(배차완료·배차취소·화물정보 이력 등)가 나옵니다. 선불·착불 오더를 배차완료로 바꾸면 수수료가 예치금에 입금됩니다. 행 더블클릭은 수정 모드입니다.
